# システム運用手順書

本書は、システムの日常運用と障害対応の手順をまとめたものです。第1章から第4章までの構成で、対象読者・前提条件・作業手順・確認方法の順に記載します。

## 第1章 はじめに

本書は、AWS 東京リージョン(ap-northeast-1)に構築するプライマリインフラストラクチャの設計書です。東京リージョンは「本番環境(Production)」と「開発環境(Development)」の 2 つの環境を同一リージョン内に共存させた構成です。

### 1.1 対象読者

本書は運用担当者を読者としています。**太字**や*斜体*、`インラインコード`も使えます。

### 1.2 前提条件

- AWS アカウントを保有していること
- 管理者権限が付与されていること
  - IAM ロールの割り当てが済んでいること
- VPN 接続が可能であること

## 第2章 事前準備

### 2.1 必要な権限

| 項目 | 内容 | 備考 |
|---|---|---|
| アカウント | 運用管理者 | 申請が必要 |
| ネットワーク | 社内 VPN | 事前に接続確認すること |
| 証明書 | 社内 CA 発行 | 有効期限に注意 |

### 2.2 確認コマンド

作業前に以下を実行して疎通を確認します。

```bash
# 接続確認。応答があれば疎通している
aws sts get-caller-identity
```

> 応答が無い場合は VPN 接続とプロファイル設定を確認してください。
